## New in 1.3.1
**Boxes look like Flash again**
Stretched windows and boxes (skill tooltips, inventory and shop frames, the server list, menus, scrollbars) now keep their rounded corners and borders at the right size, like in Flash. Before, the corners were stretched along with the box.

**Smoother with frame generation and FPS overlays**
Moving the mouse no longer makes Mugetsu send the same picture to the screen again. Lossless Scaling and FPS counters now see exactly the game's frames (a steady 30 at AQW's default), which gives frame generation even, evenly spaced frames to work with, and saves a little work on every PC.

**Open source**
Mugetsu's source code is now public under the GPL-3.0 license, in the [source folder](https://github.com/mugetsu-aqw/mugetsu/tree/main/source), and this release was built from it by GitHub Actions. Anyone can read exactly what Mugetsu changes, or build it themselves.
