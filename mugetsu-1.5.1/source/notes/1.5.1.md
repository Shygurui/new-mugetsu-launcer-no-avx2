## New in 1.5.1
**Linux version**
Mugetsu now comes for Linux too, built by the same GitHub workflow from the same source. It uses Vulkan, or OpenGL where Vulkan isn't available; right-click the game → **Graphics** to choose. On Linux, keys are read by their position on the keyboard and no longer stay pressed after switching windows. Thanks to JonasAlv for the Linux build script, menu and keyboard fixes.

**Flash-style edge smoothing fixes**
- Some shapes had small holes or gaps (for example on some armors). Fixed.
- Outlines of shapes squashed in one direction (for example effects on the ground under characters) were drawn too thick. Fixed.
